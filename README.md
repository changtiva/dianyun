# dianyun

数据标注业务的工具与测算页面集合。

## 数据标注计件薪酬计算器

`数据标注计件薪酬计算器.html` —— 面向兼职数据标注人员的计件薪酬测算工具。

核心公式：**时薪 = 单价 × 产能**

功能：

- **核心测算**：单价、产能（帧/小时）数字框与滑块双向联动，实时算出时薪 / 日薪（8h）/ 月薪（22 天），并给出非全日制最低工资合规判定
- **敏感性曲线**：对数横轴展示 5–1000 帧/小时的产能区间，标注 21 / 30 / 50 元三条参考线并高亮当前点
- **反向测算**：给定目标时薪，反推所需单价
- **项目总成本测算**：总帧数 × 单价
- **产能敏感性对照表**：6 档典型产能按合规状态着色，高亮当前行

直接用浏览器打开即可使用，无需任何依赖（图表走 CDN）。
