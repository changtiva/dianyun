# dianyun

数据标注业务的工具与测算页面集合。

🌐 在线访问：https://changtiva.github.io/dianyun/

## 数据标注计件薪酬计算器

`index.html` —— 面向兼职数据标注人员的计件薪酬测算工具（本仓库首页）。

核心公式：**时薪 = 单价 × 产能**

功能：

- **核心测算**：单价、产能（帧/小时）数字框与滑块双向联动（输入越界在失焦后自动夹紧回填），实时算出折算时薪
- **产能换算与工时**：产能可用「帧/小时」「帧/分钟」「帧/天」任一口径填写，三者自动联动换算，并给出单帧耗时；「每天工作」小时数可调，直接决定日薪与月薪估算
- **合规判定**：标尺直观显示当前时薪在 0–60 元区间中的位置，按 21 / 30 / 50 元三档阈值着色，并给出距下一档的具体差距
- **手机单屏适配**：窄屏自动切换紧凑版式，全页内容可在一屏内完整显示（已实测 360×640 / 375×667 / 390×844 / 430×932 均无需滚动）

测算公式：时薪 = 单价 × 产能；日薪 = 时薪 × 每天工时；月薪 = 日薪 × 22。

直接用浏览器打开即可使用，无需任何依赖（无外部 CDN，可完全离线运行）。
