# dianyun

数据标注业务的工具与测算页面集合。

🌐 在线访问：https://changtiva.github.io/dianyun/

## 数据标注计件薪酬计算器

`index.html` —— 面向兼职数据标注人员的计件薪酬测算工具（本仓库首页）。

核心公式：**时薪 = 单价 × 产能 × 通过率**（单价按「元/合格帧」结算）

功能：

- **核心测算**：单价（元/帧）、产能（帧/小时）、通过率（%）三个数字框与滑块双向联动（输入越界在失焦后自动夹紧回填），实时算出折算时薪（保留两位小数）
- **通过率折损**：质检验收比例直接进入测算 —— 有效产能 = 产能 × 通过率，时薪按有效产能结算；同时给出「未计通过率」的标称时薪作对照，通过率低于 80% 时提示先解决标注规范与培训问题
- **产能换算与工时**：产能可用「帧/小时」「帧/分钟」「帧/天」任一口径填写，三者自动联动换算，并展示有效产能及其换算关系、单帧耗时；「每天工作」小时数可调，直接决定日薪与月薪估算
- **合规判定**：标尺直观显示当前时薪在 0–60 元区间中的位置，按 21 / 30 / 50 元三档阈值着色，并给出距下一档的具体差距
- **全设备响应式**：字号 / 间距 / 圆角采用 `clamp()` 流体令牌，随视口平滑缩放；手机、平板、笔记本、桌面各自适配，横向不溢出、纵向不重叠
- **手机端自适应填充**：纵向节奏改用 `dvh` 流体化，矮屏保持紧凑、高屏自动放大间距；说明与页脚按屏高分档显示精简 / 完整文案，避免底部出现大片空白
- **触屏友好**：触屏设备自动放大数字框与滑块热区；刘海屏通过 `env(safe-area-inset-*)` 自动避让

测算公式：有效产能 = 产能 × 通过率；时薪 = 单价 × 有效产能；日薪 = 时薪 × 每天工时；月薪 = 日薪 × 22。

直接用浏览器打开即可使用，无需任何依赖（无外部 CDN，可完全离线运行）。
