# dianyun

数据标注业务的工具与测算页面集合。

🌐 在线访问：https://changtiva.github.io/dianyun/

## 数据标注计件薪酬计算器

`index.html` —— 面向兼职数据标注人员的计件薪酬测算工具（本仓库首页）。

核心公式：**时薪 = 单价 × 产能**

功能：

- **核心测算**：单价、产能（帧/小时）数字框与滑块双向联动（输入越界会自动夹紧），实时算出折算时薪 / 日薪（8h）/ 月薪（22 天）
- **场景预设**：内置 5 档典型产能（视频口径 750、帧级初筛 400、简单分类 200、3D 拉框 30、框选+分割 12 帧/小时），一键套用
- **合规判定**：标尺直观显示当前时薪在 0–60 元区间中的位置，按 21 / 30 / 50 元三档阈值着色，并给出距下一档的具体差距

直接用浏览器打开即可使用，无需任何依赖（无外部 CDN，可完全离线运行）。
